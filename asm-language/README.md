# ASM Language

Syntax highlighting for Assembly language in VSCodium / Visual Studio Code.

## Installation

Open VSCodium and press:

`Ctrl + Shift + P`

Then select:

`Developer: Install Extension from Location...`

Select the `asm-language` folder.
